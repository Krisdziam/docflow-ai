# Milestone 8 — QA and Portfolio Delivery

**Status:** Not started

## Objective

Verify the agreed product scope and produce an honest, reproducible portfolio case supported by tests and measured fixture results.

## In scope

- Complete fictional set of 15–20 representative documents.
- Unit, integration, end-to-end, error-path, and regression testing.
- Mobile and desktop verification.
- Accessibility and security checklist.
- Clean-environment setup verification.
- Architecture and setup documentation aligned with actual implementation.
- Demo script, screenshots, measured metrics, and Upwork case description.

## Non-goals

- Invented metrics or unsupported accuracy claims.
- Public deployment, repository publication, or paid services without approval.
- Adding new features solely for presentation value.

## Acceptance criteria

- The agreed document types complete the verified demo flow.
- Critical error, duplicate, low-confidence, and approve/reject scenarios pass.
- README setup succeeds in a clean controlled environment.
- No secrets or real personal/financial data are present.
- Portfolio statements trace to observed test or fixture evidence.
- Remaining limitations are clearly documented.

## Stop condition

Project delivery requires user review. Publishing or deployment is a separate explicit action.
